# B站大肥鱼过滤器（DeepSeek 机器人）

在 B 站视频评论区识别 DeepSeek「大肥鱼」机器人的**主评论**，在「最热 / 最新」里隐藏它们，并新增一个「大肥鱼」视图：只保留机器人主评论及其楼中楼。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 安装脚本：[dist/bili-deepseek-filter.release.user.js](dist/bili-deepseek-filter.release.user.js)
   - 或从 Greasyfork 安装（发布后）
3. 打开任意 B 站视频页，评论区「最热 / 最新」右侧会出现「大肥鱼」

## 功能

- **自动识别**：昵称词典（大肥鱼 / 鲸鱼娘 / 本鱼 / DeepSeek…）+ 角色化文风（本公主、主人、搬砖、颜文字）+ 跨账号复读，加权打分
- **两档强度**：标准（少误杀）/ 激进（宁可多抓）
- **大肥鱼视图**：隐藏真人主评论，只留机器人主评论及其楼中楼；再点一次或点原生 tab 即可返回
- **自定义屏蔽词**：与内置词典同级参与打分（昵称 +4 / 正文 +2，合计上限 +6）
- **手动白 / 黑名单**：输入用户名全称加入，白名单永远显示、黑名单永远隐藏
- **不做自动学习**：判定只由规则 + 你的手动名单决定，不会因为某次判定就永久生效

## 判定口径

| 信号 | 命中 | 权重 |
|---|---|---|
| 昵称 | DeepSeek / 深度求索 | +6 |
| 昵称 | 大肥鱼 / 鲸鱼娘 / 本鱼 / 鲸… | +4 |
| 昵称 | 只含「鱼 / 鲸」 | +2 |
| 文风 | 角色化自称（本公主 / 本鱼 / 我作为一条大肥鱼） | +3 |
| 文风 | 「主人」 | +2 |
| 文风 | 鱼生梗（搬砖 / 白饭 / 鸡腿 / 房租） | +1/个（上限 2） |
| 文风 | 颜文字 / `[doge]` | +1 |
| 文风 | 口播求认同（厉害吧 / 陛下不好啦） | +1 |
| 页面 | 跨账号逐字重复（≥24 字） | 直接判定 |

标准阈值 5，激进阈值 3。**主题词（大肥鱼、故宫、四毛钱）不计分**——真人也在聊同一话题。

## 开发

```bash
npm install
npm test              # node:test + jsdom
npm run build         # 开发版（带 [bdf] 日志与 __bdf 诊断）
npm run build:release # 发布版（剥离日志与诊断）
```

源码结构：

```
src/
  main.js            装配、重试、看门狗
  adapters/          v1/v2/v3（含 Shadow DOM）三套评论区适配
  core/
    lexicon.js       内置词典
    score.js         打分与阈值
    repeat.js        跨账号复读检测
    store.js         设置、屏蔽词、手动名单
  ui/mount.js        tab / 设置面板 / 视图切换
```

## 已知限制

- 只支持桌面版 `www.bilibili.com` 视频页；移动端与其他页面不生效
- 依赖 B 站 DOM，改版后可能失效；失效时脚本会安静退化，不影响页面
- 大肥鱼视图通过隐藏真人评论实现，评论区会变短（滚动位置会尽量保持）
